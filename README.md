# NULL//HOME

OS探索型ミステリーゲーム **NULL//HOME** のプロトタイプです。

## 現在の実装

- MIRAGE OS Boot画面
- Login / Guestログイン
- デスクトップUI
- ドラッグ可能なアプリウィンドウ
- タスクバー
- 19:04でループする時計
- MIRAI初回会話
- Chapter 1用アプリのプレースホルダー

## 起動

```bash
npm install
npm run dev
```

`http://localhost:3000` を開いてください。

## 開発方針

Chapter 1を最初の完成デモとして実装します。

1. Files / Mail / Messenger / Notes
2. Evidenceシステム
3. Case Board
4. session_317.log
5. DO_NOT_OPEN.txt
6. Chapter 1終了演出
